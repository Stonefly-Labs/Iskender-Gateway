# Data Model: ISK-0002 — Public Contracts & Versioning Discipline

These are in-memory contract types and committed files. Nothing is stored in a database (FR-044). Namespaces sit under `Iskender.Core.Contracts`. Signatures are given only where a requirement depends on them; the published contract, [contracts/public-contracts-and-versioning.md](contracts/public-contracts-and-versioning.md), holds the rules.

## Contract types

### Versioning (`Iskender.Core.Contracts.Versioning`)

| Type | Shape | Rules |
|---|---|---|
| `ContractPackageAttribute` | Assembly attribute: `ContractId` (string), `Version` (int) | One per public contract assembly. `ContractId` is `core-contracts`, `providers-abstractions`, or `policy-sdk` (FR-029) |
| `ContractVersionAttribute` | Type and member attribute: `ContractId`, `Since` (int) | On every public type, and on every member added after its type (FR-027). `ContractId` equals the assembly's |
| `WireContract` | `Id` (string), `CurrentVersion` (int), `SupportedVersions` (ordered ints) | Registered in `WireContracts`: `error-envelope` and `resource-id`, each at version 1 with `[1]` supported (FR-028) |

### Identifiers (`Iskender.Core.Contracts.Identifiers`)

| Type | Shape | Rules |
|---|---|---|
| `ResourceType` | Sealed. `Name`, `Prefix`, `Status` (`Active`, `Retired`), `Since`. Internal constructor | Declared only in `ResourceTypes` (H5). Prefixes unique, 2 to 8 lowercase ASCII letters, never reassigned (FR-008). `req` is reserved for `RequestCorrelationId` and never registered |
| `ResourceId` | Sealed, immutable. `Type`, `Value` (canonical text). `New(ResourceType)`, `Parse(string, ResourceType)`, `TryParse(string, ResourceType, out ResourceId?, out ErrorCode?)` | Text `<prefix>_<26 base32>`, at most 35 characters (FR-005, research R6). No owner, time, sequence, or host (FR-006). `New` on a retired type fails with `core.resource_id.retired_type` |
| `OwnerScope` | Abstract, with sealed `OrganizationScope(ResourceId Organization)`, `ProjectScope(ResourceId Organization, ResourceId Project)`, and `OperatorScope` (one static `Instance`) | Each constructor checks that the IDs have the right type. Equality is by kind and IDs. No conversion operators. `OperatorScope` never equals the other two (FR-010) |
| `ScopedResourceReference` | Sealed. `Id`, `Owner`. No public constructor | Created only by `OwnershipResolver.Attest` (FR-011, research R7) |
| `OwnershipResolver` | Public abstract class with `protected static ScopedResourceReference Attest(ResourceId, OwnerScope)` | Derived only by types that rule H6 allows. The list starts empty |
| `ProviderNativeId` | Sealed. `Provider` (string, 1 to 64 characters), `Value` (string, 1 to 256 characters, no control characters) | Not convertible to or from `ResourceId`, and carries no owner (FR-013) |

### Request context (`Iskender.Core.Contracts.Context`)

| Type | Shape | Rules |
|---|---|---|
| `GatewayExecutionContext` | Sealed. Created with `CorrelationContext`, `DateTimeOffset Deadline`, `CancellationToken`, `TimeProvider`. Set-once: `Owner` (`OwnerScope`), `Endpoint` (`ScopedResourceReference` of type endpoint), `ConfigurationRevision`. Views: `Principal`, `RoutingAttempts`, `BudgetReservations`, `PolicyExecution`. `IsExpired`. `ForExtension()` returns an `ExtensionContextView` | No static or ambient state (FR-018). A second `Resolve*` fails with `core.context.already_resolved`, and reading an unresolved slot fails with `core.context.not_resolved` (FR-014). `ResolveEndpoint` rejects a reference whose type is not endpoint, with `core.resource_id.wrong_type`. `IsExpired` is true once `TimeProvider.GetUtcNow() >= Deadline`, including at creation (FR-019) |
| `ConfigurationRevision` | Sealed. `Value`: 1 to 64 characters of `a-z`, `0-9`, `.`, `-` | Opaque marker. ISK-0057 decides what it names |
| `CorrelationContext` | Sealed. `RequestId` (`RequestCorrelationId`), `TraceId` (`ActivityTraceId`), `SpanId` (`ActivitySpanId`), `CallerValue` (string or null), `CallerValueDropped` (bool) | The caller value follows research R12 and is never used as a key or template (FR-016) |
| `RequestCorrelationId` | Sealed. `New()`, `Value` (`req_` and 26 base32 characters) | Generated by the gateway. Not a `ResourceId` |
| `PrincipalView`, `RoutingAttemptView`, `BudgetReservationView`, `PolicyExecutionView` | Sealed, empty, no public constructor | Later specs add members, which is compatible (FR-015, AV-1) |
| `ExtensionContextView` | Sealed, read-only. `Owner`, `Endpoint`, `ConfigurationRevision`, `Deadline`, `CancellationToken`, `Correlation` | No `Resolve*`, no service provider, no storage handle, no secret (FR-017) |

State of a set-once slot:

```text
Unresolved --Resolve(value)--> Resolved(value)
Unresolved --read--> fails core.context.not_resolved
Resolved   --Resolve(any)--> fails core.context.already_resolved; value unchanged
```

### Errors (`Iskender.Core.Contracts.Errors`)

| Type | Shape | Rules |
|---|---|---|
| `ErrorCategory` | Sealed, private constructor. `Id`, `RetryRule` (`Never`, `WhenResetKnown`, `BeforeOutputOnly`, `BeforeOutputWhenRetriable`). 13 static instances | Closed set (FR-020) |
| `ErrorCode` | Sealed, internal constructor. `Id`, `Category`, `Meaning`, `SafeMessage`, `Status`, `Since` | Declared only in `ErrorCodes` (H5). IDs match `^[a-z][a-z0-9_]*(\.[a-z][a-z0-9_]*)+$` (FR-021) |
| `OutputVisibility` | Enum with explicit values: `None = 0`, `Visible = 1` | Whether streamed output had reached the client |
| `RetryAdvice` | Sealed. `RetryAfter` (`TimeSpan?`). `Retriable` flag for `upstream_failed` | Accepted only where the category's rule allows (FR-020, FR-024, FR-025). Serialized as whole seconds, rounded up |
| `ProviderErrorMetadata` | Sealed. `Provider` (string, 1 to 64 characters of `A-Z`, `a-z`, `0-9`, `.`, `_`, `-`), `ProviderRequestId` (`ProviderNativeId`), `ProviderErrorCode` (string, at most 64 characters of `A-Z`, `a-z`, `0-9`, `.`, `_`, `-`, or null) | A provider code stays here and is never promoted to `GatewayError.Code` |
| `ErrorDiagnostics` | Sealed. Internal detail: free text and key-value pairs. `ToString()` returns `[withheld]` | Never read by the envelope codec (FR-023) |
| `RedactionStatus` | Enum with explicit values: `None = 0`, `Withheld = 1` | `Withheld` whenever diagnostics or provider detail held anything not shown, and always for the `not_found` category (TR-3, SC-006) |
| `GatewayError` | Sealed. `Code`, `Category` (from the code), `SafeMessage` (from the code), `CorrelationId`, `Retry`, `Provider`, `Redaction`, `Diagnostics`. Created by `GatewayError.Create(code, correlation, visibility, retry?, provider?, diagnostics?)` | Fails with `core.error.unregistered_code`, `core.error.retired_code`, or `core.error.retry_not_permitted` (FR-024). `visibility == Visible` rejects any advice (FR-025) |
| `GatewayException` | Exception carrying a `GatewayError` | How contract types fail with a registered code (FR-042) |
| `ErrorEnvelopeCodec` | `Write(GatewayError) -> byte[]`, `Read(ReadOnlySpan<byte>) -> ErrorEnvelope` | Version 1 format in the contract. Reading accepts every supported version |

### Initial error codes

| Code | Category | Meaning |
|---|---|---|
| `core.resource_id.malformed` | `invalid_request` | The text is empty, too long, or not `<prefix>_<body>` |
| `core.resource_id.unknown_type` | `invalid_request` | The prefix is not registered |
| `core.resource_id.retired_type` | `invalid_request` | The prefix is retired |
| `core.resource_id.wrong_type` | `invalid_request` | The ID is a valid ID of another type |
| `core.resource_id.non_canonical` | `invalid_request` | The body has upper case, a character outside the alphabet, or set pad bits |
| `core.resource.not_found` | `not_found` | Missing, or not visible to the caller (TR-3) |
| `core.context.already_resolved` | `internal` | A set-once context value was resolved twice |
| `core.context.not_resolved` | `internal` | A context value was read before it was resolved |
| `core.error.unregistered_code` | `internal` | An error was built with a code not in the registry |
| `core.error.retired_code` | `internal` | An error was built with a retired code |
| `core.error.retry_not_permitted` | `internal` | Retry advice was given where the category or visibility forbids it |
| `core.random_source_failed` | `internal` | The secure random source failed |
| `core.value.invalid` | `invalid_request` | A bounded value, such as a revision or provider ID, is outside its limits |
| `core.deadline_exceeded` | `deadline_exceeded` | The request's deadline passed |
| `core.cancelled` | `cancelled` | The request was cancelled |
| `core.internal` | `internal` | An unexpected gateway fault |
| `identity.unauthenticated` | `unauthenticated` | No valid credential was presented |
| `identity.auth_denied` | `permission_denied` | `docs/08` reason, research R10 |
| `policy.model_disallowed` | `permission_denied` | `docs/08` reason |
| `governance.quota_exceeded` | `limit_exceeded` | `docs/08` reason |
| `governance.budget_blocked` | `budget_blocked` | `docs/08` reason |
| `routing.no_healthy_backend` | `upstream_unavailable` | `docs/08` reason |

Each has status `active` and `Since` 1. The contract's Error codes table publishes the meanings and safe messages, and rule H4 checks it against the registry.

## Committed files

All are under `tests/Iskender.Contracts.Compatibility.Tests/` unless stated.

| File | Content | Rules |
|---|---|---|
| `baselines/<contract>.surface.txt` | One canonical line per public item, sorted (research R2). Empty for a package with no public types | Must equal the current surface (H3). Compared with its version at the base (R3) |
| `baselines/registries.json` | Error categories, error codes, resource types, and wire contracts with every compared field | Same rules as surface baselines |
| `break-record.json` | `{ "entries": [ { contract, item, kind, reason, approvedBy, version, date } ] }` | `approvedBy` is `Architecture (ADR) owner` (FR-033). History is immutable (H2) |
| `fixtures/wire/<contract>/v<n>/*` | Serialized examples per supported version. `resource-id` holds `valid.txt` and `invalid.txt` with the expected code per line | Must exist for every supported version (FR-035, FR-037) |
| `fixtures/breaks/<rule>/before.*`, `after.*` | Wire and registry negative fixtures | One per W and G rule (FR-038) |
| `fixtures/compatible/*` | Additive-change pairs that must pass | FR-038 |
| `tests/Iskender.Contracts.Compatibility.Fixtures/Kinds/<rule>/` | Compiled `Before` and `After` namespaces per S rule | Research R5 |

Surface line format:

```text
<kind> <key> | <attribute>=<value>; ...
```

For example:

```text
method Iskender.Core.Contracts.Identifiers.ResourceId::Parse(System.String,Iskender.Core.Contracts.Identifiers.ResourceType) | access=public; static; returns=Iskender.Core.Contracts.Identifiers.ResourceId!; params=text!,expected!; since=core-contracts@1
```

`!` marks non-nullable and `?` nullable.

## Relationships

```text
ResourceType 1 ── * ResourceId
ResourceId ── OwnerScope (Organization, Project) ── ScopedResourceReference ◄── OwnershipResolver.Attest
GatewayExecutionContext ── OwnerScope, ScopedResourceReference(endpoint), ConfigurationRevision, CorrelationContext, views
ErrorCategory 1 ── * ErrorCode 1 ── * GatewayError ── ProviderErrorMetadata ── ProviderNativeId
ContractPackage 1 ── * ContractVersion tags; baseline 1 per package; WireContract 1 ── * fixtures per version
```
