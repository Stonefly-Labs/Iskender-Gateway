# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/Stonefly-Labs/Iskender-Gateway/security/advisories/new).
Do not open a public issue, pull request, or discussion for a suspected vulnerability.

Please include the affected commit or version, reproduction steps, and the impact you observed. Remove
real credentials and personal data from anything you attach.

The maintainer will acknowledge your report, keep you informed while it is investigated, and credit you
when a fix is published, unless you prefer to stay anonymous.

## Supported versions

Iskender Gateway has no released versions yet. Fixes land on `main`.
